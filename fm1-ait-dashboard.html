Date sync · scheduling & dependency rules

Works out where each FDI activity should be from its Scheduling Rule, Rescheduling Rule, Duration (wh), “depends on” links, Dependency Rules and the working calendar, then writes only the rows you tick. Uses the tasks currently shown by the Gantt filters. Stream and Block issues are never moved.
How the rules work
Scheduling Rule (working time of the task): General calendar rule = 08:00–16:00 (Mon–Fri) · Specific – Saturday work and Specific – Everyday work = same window for now (rule definition to be confirmed) · Specific – General waiver 24/7 = every hour, also weekends and closed days · Fixed start = never moved. Empty = General calendar rule. Times are Munich.
Duration (wh) = working hours. End = Start + Duration worked inside the rule's hours, skipping closed days (Calendar section).
Dependencies = YouTrack “depends on” links. Type per link in the successor's Dependency Rules field, e.g. FDI-3:BB+2h, FDI-8:EE. EB (default) = start after the predecessor ends · BB = start with it · EE = end with it. Lag in hours, can be negative.
Rescheduling Rule: Earliest = move the task to the earliest slot its predecessors allow (earlier or later) · Latest = move it to the latest slot that still finishes before its successors need it · Date = the task starts on its Start Date and Time and is never moved by the rules (empty = same); a predecessor that pushes it later is reported as a conflict. Only State = Planned tasks are moved.
Rescheduling rows move a task because of a dependency (ticked by default). Open-hours alignment rows only snap Start/End to the rule's working hours. In FDI most windows (Start → End) are much longer than Duration (wh), so alignment would shorten End to Start + Duration — that is why these rows are not ticked. Check them before writing.
Before each write the proxy re-reads the issue: if Start or End changed in YouTrack since your preview, that row is skipped. Every write is read back and logged in fm1-sync-log.jsonl next to the proxy.

Teams · capacity & utilisation

Type each team's available headcount in the second column, saved on this computer only. It is not written to YouTrack or the Excel. Leave blank if unknown. Planned effort includes undated activities; "in horizon" is the part inside the selected year.

Cleanup · tasks that should already have started

Open activities and milestones (not Done / Canceled) whose Start is on or before the chosen date. Read-only list: update them in YouTrack or with the ✎ button in the Gantt.

Working calendar · company closures

Mon–Fri are open, weekends and Bavarian public holidays are closed. Add company closures (e.g. TEC Munich closing) or exceptional open days. Used by the Gantt hatching, the planning engine, Date sync and the “Working calendar” load mode. Save calendar stores it with the local proxy (fm1-working-calendar.json) so it is shared by every browser on this PC.
